Why: the live Mac and Vision sets are still the 2.8 set. They say 156 cities / 117 campuses (now 166 / 122)
and show nothing of Then & Now, the 2.18 headline feature the iPhone/iPad set now opens with.

## Look

Same look as the 2.18 iPhone/iPad set (`store-screenshots/final`): orange background, a sentence-case
headline with one phrase on a dark "chip" (written `*like this*` below), a small line under it, and the
real app windows underneath. The 2.8 shouting-verb style (`FLY / THROUGH 156 CITIES`) is dropped so all
platforms tell one story.

Sizes: Mac 2880 x 1800, Vision 3840 x 2160. 10 languages each. Only the text changes per language;
the app pictures are English captures (as in 2.8, and as the iPhone set is today).

## How it gets built (after approval)

1. Build Stamped from main in this worktree for Mac and the visionOS simulator (copying in the ignored
   Info.plist and the Detroit model only if the build needs them; not staged).
2. Seed demo stamps/trips the way 2.8 did, without editing app source: if that needs launch hooks,
   I'll ask first. Capture each window with `screencapture -l` (Mac) and `xcrun simctl io` (Vision).
3. New `screenshots/2.19/render_locales.py` + `compose_wide_2_19.py` draw the 2.18 look; writes
   `screenshots/2.19/{mac,vision}/<locale>/01.png …` and `screenshots/2.19/overview.png`.
4. Nothing is uploaded. That waits for a 2.19 version in App Store Connect (2.18's screenshots are locked).
